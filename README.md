# Hybrid Automation Framework

A robust, scalable, and maintainable **Hybrid Test Automation Framework** built using **Selenium**, **Java**, **TestNG**, **Maven**, and **Page Object Model (POM)** concepts.  
This framework supports Web UI automation with clean architecture, modular components, reusable utilities, and extensibility for CI/CD.

---

## 🚀 Features

- 📁 Hybrid framework structure (Data-Driven + Keyword + Modular)
- 🧪 Built on **TestNG** for parallel execution and reporting
- 🧱 Page Object Model (POM) implementation
- 🛠️ Utility classes for WebDriver, waits, screenshots, logs, etc.
- 📝 Centralized configuration with `config.properties`
- 🔄 Supports cross-browser execution
- 📊 Extent Reports integration (if included)
- 📦 Maven for dependency management
- 🤝 Easy to integrate with Jenkins / GitHub Actions CI/CD pipelines
